--------------------------------------------------------------------------------
NOTES
--------------------------------------------------------------------------------
1. THE TWO VENDOR DOCUMENTS DISAGREE on three X4-36 electrical values and on
   backlash for all four. [PM] is newer (2026-08-04) than [UM] (2025-05-16), so
   prefer [PM] where they conflict. Both values are printed above rather than
   silently picking one. None of the disagreements touch torque, speed, ratio,
   current, inertia or back-drive torque.

2. "Inertia (kg.cm2)" is printed with NO statement of what it is referred to.
   If it is motor-side rotor inertia then the reflected value is the row in the
   derived block. If it is already output-referred it is 3-4 orders of magnitude
   too small to be the dominant term at the joint. The arithmetic is given so
   the assumption is visible; it has NOT been confirmed with the vendor.

3. The torque constant is OUTPUT-SIDE, confirmed by the vendor's own numbers:
       X8-120   17.6 Arms * 2.4 = 42.2 N.m  vs  rated 43     (2% )
       X6-60     9.5      * 2.1 = 20.0      vs  rated 20      (0% )
       X12-320  30.0      * 3.3 = 99.0      vs  rated 85     (16%)
       X4-36     6.1      * 1.9 = 11.6      vs  rated 10.5   (10%)
   So KT already includes the gear ratio. Do not multiply by it again.

4. THE X4-36 NAME IS SELF-CONTRADICTORY IN THE VENDOR'S OWN DOCUMENTS.
   [UM] Table 3-1 says the 4th field of the part number is PEAK TORQUE, and
   [UM] Table 3-2 lists the full name as RMD-X4-P36-36. But both [UM] Table 3-3
   and [PM] p4 print PEAK TORQUE = 34 N.m. The gear ratio is also 36.
   So "36" in the name is not reliable; 34 N.m is the specified peak.
   For the other three the name and the parameter table agree
   (X6 60/60, X8 120/120, X12 320/320).

5. X6-P20 and X8-P20 share gear ratio 19.612 exactly. X12-P20's ratio is a
   round 20, NOT 19.612 -- easy to assume otherwise from the "P20".

6. BACK DRIVE TORQUE is the vendor's own Coulomb-friction-like figure and is
   the right field to source a simulator's `frictionloss` from. It is published
   for all four here and is absent from [UM] Table 3-3 -- it appears only in the
   per-model product pages.

   CONFLICTING VALUE ON RECORD for X8-120. MyActuator's GENERAL CATALOG 2025
   lists X8-120 back drive torque as 3.21 N.m. Both local 2026-08-04 documents
   ([PM] p8 and [DS]) print 1.5 N.m. 1.5 is used here because (a) those two are
   newer and mutually independent, and (b) the one hardware measurement on this
   robot -- 1.44 +- 0.14 N.m, free-swing elbow pendulum decay -- agrees with 1.5
   to 4% and with 3.21 not at all. If you ever see 3.21 quoted, it is the 2025
   catalog.

7. [UM] TABLE 3-3 HAS A MISLABELLED ROW. Its row headed "Repeatability
   (Degree)" reads 0.17 / 0.25 / 0.3 / 0.66 / 1.5 / 2.4 / 12.9 / 31.6 across the
   eight models. Those are the INERTIA values in Kg.cm2 -- identical, in the same
   model order, to the "Inertia" row on the [PM] per-model pages. A repeatability
   of 12.9 degrees is also absurd for a module the same table rates at <0.01 deg
   control accuracy. So: Table 3-3 publishes no usable repeatability figure, and
   anyone reading Table 3-3 alone would wrongly conclude inertia is unpublished.
   Actual repeatability: NOT PUBLISHED.

8. NO-LOAD CURRENT IS DC BUS CURRENT, NOT PHASE CURRENT. [PM] names the row
   "No-Load INPUT Current (A)" while the torque constant is defined per Arms of
   PHASE current. So i0 * KT mixes two different currents and is not
   dimensionally sound -- it also sweeps in inverter and iron losses. It is
   retained above only as a loose upper bound. Where a Coulomb friction figure
   is wanted, prefer BACK DRIVE TORQUE, which the vendor measures at the output
   and publishes directly.

--------------------------------------------------------------------------------
FOR RL TRAINING, THE SHORT VERSION
--------------------------------------------------------------------------------
Use, straight from the vendor:
  effort_limit  = peak torque        34 / 60 / 120 / 320 N.m
  continuous    = rated torque       10.5 / 20 / 43 / 85 N.m
  frictionloss  = back drive torque  1.14 / 1.6 / 1.5 / 3.8 N.m
  velocity cap  = no-load speed      11.62 / 18.43 / 16.55 / 13.09 rad/s
  torque/current= KT (output-side)   1.9 / 2.1 / 2.4 / 3.3 N.m/A

Do NOT take from the vendor without deciding the convention first:
  armature -- the published "Inertia" has no stated reference frame (note 2).

Not published at all, so either measure it or randomise over it:
  viscous damping, torque ripple, current-loop bandwidth, thermal time
  constants, friction vs temperature.

The stall table is the only thermal information that exists. For a humanoid
that stands still, it is the binding constraint: an X8 at 86 N.m -- twice its
43 N.m rating -- is rated for 10 seconds.
