# deploy_v11h27k — HV1V2 leg policy with variable pelvis height

- **Policy:** v11h, `model_26999`. It was fine-tuned from v11g `model_19000` for 8000 iterations.
- **Task:** `Mjlab-Velocity-Flat-HV1V2-Decoupled-v11h`.
- **Training run:** `logs/rsl_rl/hv1v2_velocity/2026-11-04_21-38-51_v11h_s43`.

## What changed from v11g (deploy_v11g19k)

There is **one new observation**, `height_cmd`. It is the **last** input, so `obs_dim` goes from 837 to **838**. Everything else is identical to v11g: the joint order, anchor, gains, action mapping, the other 837 inputs, upper-body handling and the twist command ranges.

```
height_cmd = h_applied - 0.97939        # metres; 0 at home, -0.0894 at the lowest
```

## Runtime rule for the height input (merai_policy)

Each 50 Hz tick, do this **before** building the observation:

1. `h_target = clamp(operator_height, 0.89, 0.97939)`
2. `h_applied += clamp(h_target - h_applied, -0.10*0.02, +0.10*0.02)`. This is a 0.10 m/s slew.
3. Observe `h_applied - 0.97939`.

**On policy activation:** set `h_applied = h_target = 0.97939` and hold home for 0.5 s. This is the same as the training reset.

**If there is no operator height input**, always feed 0. The policy then behaves like v11g at home height.

Do not:
- feed a value outside [0.89, 0.97939]: the policy never saw it;
- step the input without the slew;
- feed the raw height: the input must be centred on home, as in the formula above.

**MNN build:** `merai_sdk/tools/policy/build_hv1v2_mnn.py` needs input width **838**.

**At home height**, v11h is as good as v11g or better on every v11 gate:

| Gate | v11h | v11g |
|---|---|---|
| Pads 4/4 loaded | 91% | 83% |
| Ankle-roll torque | 4.2 N·m | 5.6 N·m |

**Squeeze gate:**
- **Hip roll:** passes at every height (5–7 N·m against a 10 N·m limit).
- **Hip pitch R−L:** fails marginally at 0.92 and 0.89 m, at 15.1–15.8 against a 15 limit.

## Known risks: watch on the robot

- **Knee torque when crouched.** The static load is about 65 N·m per knee at 0.89 m, and the sim measures R 61 / L 71 N·m. The continuous rating is 85 N·m, so long low crouches or walks are thermally limited. Watch knee temperature, the **left** knee especially, because the policy loads it more when crouched.
- **Less ankle-pitch margin** at the bottom of the range, about 0.2 rad.
- **Rising lags** the command by 1–2 cm while it slews up.

**Suggested robot ladder:**
1. On the crane: standing height steps.
2. On the floor: standing height steps.
3. Slow walk at 0.95 m.
4. Slow walk at 0.89 m.
